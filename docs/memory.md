# Memory — постоянный контекст проекта

Короткая память для людей и AI-агентов: что это за проект, какие решения приняты и почему, что открыто.
Обновлено: 2026-10-27.

## 1. Проект

- Репозиторий: `lemnity/bk` (GitHub), ветка `main`, публикация — GitHub Pages
  https://lemnity.github.io/bk/ (обновляется через 1–2 минуты после пуша).
- Что это: кликабельный прототип сайта продажи билетов театра и кабинета администратора. Без бэкенда,
  данные — демо в коде и localStorage.
- Соседний проект `../trds` — полноценная система театра TURDUS (Next.js + Payload). Из него взяты данные
  афиши (`src/modules/shows/demo-data.ts`) и формат документов `docs/`.

## 2. Инварианты (не ломать)

1. Отчёт на экране = все его выгрузки (Word, Excel, CSV, печать) — выгрузки берут снимок показанной модели.
2. Письмо: копия = скачанный файл = отправляемый HTML (`toHtml`); плейсхолдеры `{{…}}` подставляются
   только в предпросмотре.
3. Пользовательский HTML — только в `<iframe sandbox="">`; ссылки — `http(s)`, `mailto`, `{{…}}`.
4. Демо-данные детерминированы (сидированный ГПСЧ, без `Math.random`/`Date.now`).
5. Бланк PPr2 отчётов «3»/«3а» (шапка, структура, формулы итогов) не меняется — меняется только источник данных.
6. Отправленную рассылку править нельзя (только просмотр).
7. `?v=N` у файла одинаков на всех страницах.

## 4. Открытые вопросы

1. **Бренд.** Заголовки и тексты — «Технологии творчества»; блок «О театре» в `promo.html` — «Тюменский
   БДТ», г. Тюмень; логотип `assets/logo.png` — «Театр Либерта»; афиша — спектакли TURDUS (Екатеринбург).
   Нужно одно название, город и логотип.
2. Ставки комиссий по каналам продаж (отчёт «3»).
3. Какие оплаты относятся к «Безналичному расчёту» (отчёт «3а»).
4. Репертуар кабинета (`S.EVENTS`: Гамлет, Чайка, Вишнёвый сад, Щелкунчик) расходится с афишей (TURDUS).
5. Нужен ли Vercel: `vercel.json` есть, проект не привязан, публикация идёт через GitHub Pages.

## 5. Как работать

- Локально: `python3 -m http.server` в корне, открыть `http://localhost:8000/`.
- Тесты: `for t in tests/*.py; do printf "%s: " $t; python3 $t | tail -1; done` (нужны Python Playwright
  и Chromium).
- Состояние кабинета сбрасывается очисткой localStorage ключа `tbdt_admin_v1`.
