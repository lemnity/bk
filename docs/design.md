# Design — визуальная система и UX

Обновлено: 2026-10-27. Полный справочник токенов и компонентов кабинета —
[admin-design-system.md](admin-design-system.md). История: редизайн 2026-06-07
(`docs/superpowers/specs/2026-06-07-modern-redesign-design.md`) — от «винтажного плаката» к современной
светлой теме.

## 1. Принципы

- **Светлая, спокойная, деловая.** Холодная сине-серая палитра, один акцент (тёмно-синий), много воздуха.
- **Театральность — ритмом, а не декором:** нумерованные секции, крупные заголовки, фото спектаклей.
- **Смысл не держится на цвете:** занятые места — штриховкой, ошибки — текстом у поля, статусы — словом.
- **Сдержанное движение:** fade + лёгкий подъём, без «прыжков»; всё выключается `prefers-reduced-motion`.

## 2. Токены

Общие для `styles.css` и `admin.css` (значения в `:root`):

| Группа | Токены |
|---|---|
| Поверхности | `--bg #F2F5F9`, `--surface #FFF`, `--surface-2 #E9EEF6` |
| Текст | `--ink #132437` (14.4:1), `--ink-2 #44556E` (6.9:1), `--ink-mute #596A82` (5.0:1 — светлее нельзя) |
| Акцент | `--accent #173A6D`, `--accent-deep #0F2A53`, `--accent-tint #E8EDF5` |
| Линии | `--line #DCE3ED`, `--line-2 #7A8DAA` |
| Статусы | `--ok #0E7A52`, `--warn #8A5B10`, `--bad #B3261E`, `--focus #2F6FE0` |
| Шрифт | `--font-disp`, `--font-ui` = Rubik (300–800) |
| Радиусы | `--r-sm 6px`, `--r 10px`, `--r-lg 14px` |
| Тени | `--sh-sm`, `--sh-md`, `--sh-lg` (мягкие, на базе `--ink`) |
| Движение | `--ease cubic-bezier(.22,.61,.36,1)`, `--t-fast .18s`, `--t .32s` |
| Сетка | `--maxw 1240px`, `--gutter clamp(20px,4vw,48px)` |

Тарифы мест — последовательная холодная шкала из 11 ступеней (`#E0ECF0` → `#9785DD`), яркость строго
убывает, номер места на самой тёмной ступени держит ≥ 5:1. Менять только с пересчётом контраста.

## 3. Типографика

- Заголовки страниц: 2.2–3.1rem, weight 500, трекинг −.03em; секции — 1.75–2.15rem.
- Надзаголовки (eyebrow/kicker): .66–.69rem, uppercase, трекинг .14em, акцентный цвет.
- Текст: .86–1rem, line-height 1.5–1.7; цифры — `tabular-nums`.

## 4. Ключевые экраны

### Публичная часть
- **Афиша** (`index.html`): шапка страницы с фильтром-чипами по типу события; сетка карточек
  (auto-fill от 280px): фото 4:3, возраст и «Премьера» бейджами, жанр, название, описание в 2 строки,
  ближайший показ, площадка, длительность, даты-чипы, «Билеты от», две кнопки «Подробнее» / «Купить билет».
- **Страница спектакля** (`show.html`): hero на фото с затемнением, факты (ближайший показ, площадка,
  длительность, цена); «О спектакле» + карточки «Создатели» и «Где проходит»; встроенный «Выбор мест»;
  галерея; «Ещё спектакли».
- **Покупка**: модальное окно с шагами «Места → Оформление → Билет», панель сеанса (даты/время), схема
  зала (легенда только действующих тарифов, сцена, ложи, партер, амфитеатр, балкон), «Ваш заказ»
  справа (липкий), итог, бонус 5%. Билет — тёмная карточка с отрывной линией.

### Кабинет
- Сайдбар с деревом разделов, профиль, «Вернуться на сайт»; контент — панели `.panel`.
- **Отчёты**: каталог с избранным и категориями; страница отчёта — форма параметров, бланк PPr2 или
  таблица с «Итого», кнопки выгрузки; печать скрывает интерфейс и оставляет заголовок и документ.
- **Конструктор письма**: панель режимов (редактор / предпросмотр / HTML), «Импорт ▾» / «Экспорт ▾»,
  ширина компьютер/телефон; холст 600px; справа «Стиль / Свойства»; режим HTML — редактор кода слева
  и живой предпросмотр справа, список предупреждений; снизу «Тестовая отправка».

## 5. Компоненты (кабинет)

Кнопки `.btn` / `.btn-gold` (основная) / `.btn-plain`, иконки строк `.rowact`; таблицы `.table-wrap` +
`.dtable`; бейджи `.badge`, теги `.tag`; формы `.rv-*` (отчёты), `.mv-*` (рассылки); тост `.toast`;
пустые состояния `.stub`, `.rep-empty`; диалог `.dlg-*` (`AdminDialog`); меню конструктора
`.lt-io-menu`, `.lt-var-menu`. Примеры разметки — в [admin-design-system.md](admin-design-system.md).

## 6. Адаптивность и доступность

- Брейкпоинты: 1040 / 980 / 820 / 760 / 680 / 560 / 420 px. На телефоне: одна колонка карточек,
  модалки на весь экран, места не меньше 23px, без горизонтальной прокрутки страницы (схема зала
  прокручивается внутри своей области).
- Фокус всегда виден (`--focus`, 2px), диалоги ловят Tab и закрываются Esc, меню — `aria-haspopup`,
  `aria-expanded`, `role="menu"`.

## 7. Состояния и тексты

- Пусто: «Нет данных за выбранный период», «Места ещё не выбраны», «Спектакль не найден» + путь назад.
- Ошибки — у поля, с действием: «Вставьте HTML-код письма», «Не похоже на адрес: …».
- Подтверждения разрушительных действий — диалог с понятным последствием («Блоки сохранятся…»).
- Тосты — короткие, по факту: «Отчёт № 1 выгружен», «HTML письма скопирован».

## 8. Известные несоответствия

- Бренд: в коде «Технологии творчества», в `promo.html` «Тюменский БДТ», на логотипе «Театр Либерта»,
  в данных афиши — TURDUS. См. [memory.md](memory.md) §4.
- Редизайн 2026-06-07 планировал Unbounded для заголовков и золотой акцент — фактически всё на Rubik,
  золото заменено синим (`--gold*` — алиасы `--accent`).
