## Бэклог: отложенные замечания ревью (можно делать в любом порядке)

### Отчёты
- ⬜ Доли % в «Итого» принудительно 100 при округлённых строках.
- ⬜ «Репертуар» теряет свои спектакли, которых нет в `EVENTS` («Ревизор», «Прощальные гастроли»).
- ⬜ 104М «подарочные сертификаты» не показывает строку сертификатов.
- ⬜ Список спектаклей в «3»/«3а» захардкожен — часть пунктов всегда пустая; брать из `AdminReportData.events()`.
- ⬜ «3а» «Продано» — нетто-счёт (добавить пояснение); «3» «Реализовано» включает приглашения.
- ⬜ Защита от некорректной даты в книге операций; CSV: проценты с точкой, защита от формул (`=`, `+`, `-`, `@`).
- ⬜ Дубли помощников option/range-key между `admin-report-doc.js` и `admin-report-view.js`.
- ⬜ Журнал: у броней/приглашений тип оплаты; возвраты не связаны с продажей; id меняются при правке зон.
- ⬜ `admin-report-kinds.js` (~530 строк) — кандидат на разбиение.

### Письма
- ⬜ Режим HTML без `</body>` — нет строки отписки и отдельного предупреждения.
- ⬜ `esc` не экранирует `'` в подстановках `renderVars`.
- ⬜ Пересекающиеся `**`/`_` дают неверную вложенность; выделение с пробелом на конце не форматируется.
- ⬜ Меню «Переменная»: стрелки, закрытие по Tab.
- ⬜ Tab/Shift+Tab в редакторе кода сбрасывает историю отмены (перейти на `execCommand("insertText")`).
- ⬜ Линтер: `style` с вложенными кавычками, ложное срабатывание на `max-width`.
- ⬜ Тестовая отправка: адреса через пробел; не разрешать на отправленных рассылках; граница «ровно 5».
- ⬜ Сид-письмо «Премьера» получает вторую подпись с отпиской.
- ⬜ Превью уже отправленных писем показывает строку отписки, которой не было.
- ⬜ `admin-letter.js` (~1600 строк) — вынести рендер, линтер и импорт/экспорт в отдельные модули.
